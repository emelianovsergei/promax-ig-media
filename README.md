# promax-ig-media

Transient **public** staging for PRO MAX HVAC & Appliance Repair Instagram / Google Business Profile API publishing. Images are pushed here for the seconds Meta/Google need to fetch them, then deleted. Nothing in `staging/` is meant to persist; do not link to files here.

Sibling of `pulse-ig-media` (PULSE HVAC). Kept separate so a PRO MAX customer photo never lands in a PULSE-named repo.
